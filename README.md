# Maroela Pub & Grill & Game Trails

Website for Maroela Pub & Grill & Game Trails, a family game farm, lodge, restaurant and wedding venue in the Loskop Valley near Groblersdal, Limpopo.

Live: https://obsidianstudiodesigns.github.io/Maroela-Pub-Grill-Game-Trails/

Static site (HTML, CSS, vanilla JS with GSAP, ScrollTrigger and Lenis). Bookings go out via WhatsApp or email, no backend.

Designed by [Obsidian Studio Designs](https://obsidianstudiodesigns.co.za/).
